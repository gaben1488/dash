# DASH — scoped instructions for `docs/**`

Читайте корневой `AGENTS.md` как общий контракт. Этот файл **дополняет**, а не отменяет его.

- Исторические планы/спецификации/ревизии не превращать в команды. Перед новым `MUST` проверь точный первичный документ, дату, статус ADR, текущий код и scope. Если решение не принято или runtime не проверен — `proposed`/`UNKNOWN`.
- При изменении документного контракта поддерживать путь источник → утверждение → статус/владелец → тест → адрес изменённого контракта. Применять `docs/engineering/AUTHORING_STANDARD.md`. Не приписывать юридические выводы проекту без редакции закона и основания.
- Исправление одной инструкции не оправдывает тотального переписывания архива. Вносить лишь семантически относящиеся изменения, оставляя датированные первички неизменными.
- Никогда не копировать в публичные документы приватные исходные реестры, ledger, сервисные ключи, содержимое SQLite, персональные данные и неосмотренные журналы.
- В разработке нескольких агентов: `main` — через PR; отдельная ветка и отдельный worktree на исполнителя; не делать `stash pop` в чужом worktree, не коммитить чужой WIP. При любом конфликте PR смотрите точный base/head SHA.
- При изменении `docs/**` обязательно проверить относительные ссылки и оставленные в тексте псевдофакты «выполнено». Проверка документа **не** означает, что тесты кода, GitHub Actions, Google Sheets или production прошли.
- Для обновления instructions для Codex/Claude/Copilot проверять фактические механизмы загрузки агента: root vs scoped, `@AGENTS.md`, `paths:` и `applyTo:`. Не копировать длинные договоры в always-on контекст.

Если task относится к предметному контракту, открыть его из `docs/contracts/`; документационные проверки описаны в `docs/engineering/AI_DOCS_CHECKS.md`.
