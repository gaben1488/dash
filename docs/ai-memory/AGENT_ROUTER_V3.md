# DASH: минимальная инструкция агенту — проект, не заменяет AGENTS.md

**Статус:** proposed; источник по состоянию на `main@90fa989fe42b27351430c70a07f380768ed106fa`, 23.10.2026. Этот файл предназначен для редакционной замены перегруженных инструкций после проверки совместимости со всеми агентами.

1. **Найди предмет и действующий дом.** Текущая очередь/готовность — `docs/PLAN.md#current-execution`; продукт — `PRODUCT.md`; архитектурные границы — `docs/ARCHITECTURE.md`; метрики — `docs/METRICS_CONTRACT.md`; безопасность — `docs/SECURITY.md`; выпуск — `docs/RUNBOOK.md` и `docs/report-engine-operating-contract.ru.md`. Исторические `docs/superpowers/{plans,specs,audits}` — свидетельства, не автоматический приоритет.
2. **Загрузи только нужный контракт.** Google-источники, деньги, формулы → `SOURCES_METRICS.md`. DOCX, RecommendationLedger, snapshot/release → `REPORT_RELEASE.md`. UI, фильтры, карточки, сигнал → `UI_WORKFLOW.md`. Документация, конфликты, память → `CHRONOLOGY_AND_MAINTENANCE.md`.
3. **Не угадывай статус.** В каждом результате называй `asOf`, Git SHA, source snapshot/revision, что проверено локально, что действительно проверено на production. `proposal`, `implemented`, `tested`, `deployed`, `owner-accepted` — разные значения. При отсутствии доказательства статус `UNKNOWN`, не `DONE`.
4. **Любая ошибка — класс дефекта.** Воспроизведи → найди общую первопричину и всех носителей → добавь отрицательный тест → проверь смежные пути → обнови один канонический контракт. Не скрывай падения и не удаляй регрессионный тест ради зелёного результата.
5. **Операции с риском.** Не менять Google Sheets, SQLite, исторические первичные данные, RecommendationLedger, доступы, VPS/production без адресного согласованного контура, снимка/backup, чтения назад, отката и приёмки. Неполное чтение никогда не перезаписывает полную подтверждённую базу.
6. **Границы команды.** Не смешивать чужой незавершённый worktree; не мерджить неготовый PR и не менять `main` посредством документационного аудита; не хранить ключи, ПДн, дампы, локальную память агента в Git. Не обходить Git hooks.
7. **Финиш по доказательствам.** Точный код/документ и SHA, тест с именем/результатом, список наблюдаемых изменений, незакрытые гейты и следующий предметный шаг. Зелёный CI не является бизнес-приёмкой.

Это навигатор, а не полный перечень инструкций. Существующий корневой `AGENTS.md` и `docs/AGENTS.md` остаются действующими до отдельного принятого перехода; при конфликте кандидат не переопределяет их.
