Используется публичный сторонний просмотрщик HTML из **публичного** Git-репозитория: он может показать предупреждение безопасности; контент не содержит ведомственных данных. Для приватной работы предпочтительнее открыть скачанный HTML локально. HTML один файл с CSS, JS и шрифтами. Внешние запросы, кроме загрузки того же файла, не нужны.

Плавающая кнопка «Dash · дизайн-гейт» раскрывает варианты: **Исходная**, **Космос**, **Камчатка**, **Минералы**, шесть отделок, все 13 настоящих страниц и реальные внутренние переключатели. Плавающий контроллер — инспектор, **не новый компонент конечного продукта**.

## Почему это НЕ старый упрощённый макет

Файл создан Vite из реальных `packages/web/src/main.tsx`, `App.tsx`, `Header.tsx`, `OrgStrip.tsx`, `pages/*`, `store.ts`, shared/core, а не из 18 записей `docs/superpowers/mockups/dash-consolidated/src/model.mjs`. Истинные страницы и обработчики остались собственными. Переключатели инспектора вызывают прежний `setPage` и кликают видимые **производственные** кнопки. Палитры 39 пар взяты из `zarya-vystavka` через source-shell PR #70; материалы накладываются только CSS без замены блоков.

Отчёт — из `Report.tsx` со всеми договорными `SectionCard`, `ReportTable`, `KpiTile`, оглавлением и тремя Word-кнопками. Существующее отсутствие `OrgStrip` на Отчёте **намеренно**: собственное оглавление по ГРБС; на остальных страницах настоящий `OrgStrip`, не новая боковая панель.

## Безопасность и достоверность

1. Источник API заменён в `src/preview/synthetic-api.ts` только после открытия **отдельной** `preview.html`, до динамического импорта настоящего приложения. GET отвечает строго проверенными примерами либо 503 «контракт не обеспечен». POST/PUT/PATCH/DELETE отвечают 409; внешние fetch блокируются. Живые Google Sheets, сервер, production SQLite и отчётные релизы не использованы.
2. Тестовые записи, наименования организаций и суммы относятся к демонстрации. Никаких личных/закупочных строк из live в публичном HTML нет. `lib/report/fixture.ts` используется как устоявшаяся fixture проекции, не как новый production расчёт.
3. `main` не менялся. Ветка добавляет только `packages/web/src/preview/`, `packages/web/preview.html`, `packages/web/vite.preview.config.ts`, скрипт сборки, CI и **скомпилированный HTML в docs**. Код источников App, Header, OrgStrip, pages, styles, store и shared/core не правился.
4. Нативные события, за которыми стоят запросы, не объявлять полностью работоспособными, пока они не прошли браузерную проверку на синтетическом API с полной контрактной формой.

## Ступени допуска (классы STOP)

**G0 — исходное содержание**. Сравнить список 13 маршрутов, 5 режимов мониторинга, 6 контроля, 3 системы, 2 реестра, 2 отчёта и остальные вложенные формы с production. Пропуск — STOP.

**G1 — браузер и интерактивность.** На ширинах 1440, 1280, 768, 390 в обеих темах открыть каждую страницу, каждую подвкладку, каждый drawer/раскрытие/модаль; проверить DOM, focus, scroll, клавиатуру, консоль и ошибки API. Пока не пройден для всех.

**G2 — семантика.** Сравнить отчётную математику, классификацию, проценты null vs 0, AD-экономию, ставки и режимы периода, организации/подведы, связи процедур/доли, no-data vs no-source. Только на Frozen source+rules_version, не на синтетике. Пока не пройден.

**G3 — работа и отказ.** Проверить редактор, черновик и версионность, сохранение исходных формул/примечаний, запреты, partial batch, конкуренцию и откат. Пока не пройден.

**G4 — утверждение владельцем.** После G0–G3 сравнить исходный/новый скриншоты каждый маршрут и состояние, зафиксировать решение. Нет разрешения заменять рабочие компоненты статическими mock-версиями.
