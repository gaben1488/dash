Безопасность редактирования

Один запуск: библиотека Figma-компонентов, варианты материалов, 26 основных экранов (13 текущих + 13 целевых), 84 сцены подразделов. Все слои редактируемые; прежние ручные правки не удаляются.

Результат

Выберите состав и нажмите «Добавить». Повторный запуск не удалит изменения.

Не только палитры: в Figma появятся независимые страницы/слои для каждого раздела и каждого внутреннего режима, рабочие макеты таблиц, карточек и подтверждений, состояния ошибок и компоненты с вариантами. Палитра и материал меняют только верхний слой языка, а не структуру данных. Сначала сравнивайте «Текущий» и «Целевой». Меняйте реальные свойства слоёв, а не скриншот. После выбора — отдельный допуск в React PR.
