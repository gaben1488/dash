# Dash: план продолжения консолидации

> Для следующего исполнителя: `superpowers:executing-plans`, задачи последовательно. Текущий владелец прямо поручил продолжить и дал ограничения; повторный вопрос о разрешении на этот прототип не нужен. Продовое внедрение остаётся самостоятельным этапом.

**Цель:** вернуть полноту исходной системы в проверяемую пробу, оставив рабочие страницы и ядро защищёнными.

**Архитектура:** настоящий HTML навигации + извлечённые пары зари + CSS действующей полосы организаций. Логика пробы отделена от приложения. Источник решений: [CONSOLIDATION-CONTRACT.md](../mockups/dash-consolidated/CONSOLIDATION-CONTRACT.md).

**Стек:** имеющийся React/Vite, без новых зависимостей.

## Ограничения и предмет проверки

- Все изменения — `docs/superpowers/mockups/dash-consolidated/`; production-страницы и исходные HTML не меняются.
- Проверяем постоянные места осей, режимы отображения, отложенное обновление, изоляцию организации, календарные границы пятничного цикла.
- Проверяем длинную навигацию, частичный выбор, светлую тему, широкую/среднюю/узкую компоновку и отсутствие скрытых столбцов при карточке.
- Неполные страницы макета не выдаются за новые версии рабочих страниц.
