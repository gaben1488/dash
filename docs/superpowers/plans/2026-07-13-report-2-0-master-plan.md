# Отчёт 2.0 — мастер-план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (recommended)
> или superpowers:executing-plans. Шаги — чекбоксы `- [ ]`.

**Goal:** Превратить dash из BI-обёртки над таблицами в живой «Отчёт 2.0» (см. спеку
`docs/superpowers/specs/2026-07-13-report-2-0-product-design.md`), не потеряв ничего рабочего
и без регресса.

**Architecture:** Существующий конвейер (ингест → расчёт → сверка → доверие → сигналы → снапшот)
сохраняется; сверху добавляется слой проекций (отчёт-проекция, реакции, словарь продукта);
7 старых страниц переплавляются в 4 раздела (Отчёт · Реестр · Лаборатория · Данные).

**Tech Stack:** TS ESM monorepo (shared/core/server/web), Fastify + Drizzle + better-sqlite3,
React 19 + Vite 6, vitest. Гейт: `pnpm typecheck` (4 пакета) + `pnpm lint` (0 ошибок) +
`pnpm -r test`.

---

## Как читать этот документ

Это **мастер-план**: он задаёт фазы, задачи каждой фазы, зависимости и DoD. Каждая фаза
получает свой **детальный план** (`docs/superpowers/plans/2026-07-13-phaseN-*.md`) с
пошаговыми задачами (файлы/код/тесты/команды) — когда до неё доходит очередь. Первый детальный
план (фаза 0) идёт следом: `2026-07-13-phase0-honesty-and-debts.md`.

Причина декомпозиции (skill writing-plans, «Scope Check»): спека покрывает несколько
независимых подсистем (проекция, реакции, переплавка 4 разделов, ЕИС, RBAC). Один плоский план
на всё был бы нечитаем и устарел бы к середине. Правило: **фаза = отдельный детальный план =
работающий тестируемый инкремент**.

## Инварианты (действуют во ВСЕХ фазах)

- **TDD**: поведение — красный тест раньше фикса (верифицировать падение по правильной причине).
- **CDD**: перед переплавкой блока — характеризационный тест пиннит его текущие числа; после —
  те же числа либо задокументированное объяснение расхождения.
- **Гейт на каждый коммит**: `pnpm typecheck && pnpm lint && pnpm -r test` = зелёные.
  `pnpm lint` ОБЯЗАТЕЛЕН для move-only (tsc не ловит осиротевшие импорты; husky гоняет только
  tsc+core-test).
- **Домен-инварианты — закон** (менять только через ADR): отклонение = факт−план; экономия
  gated по флагу AD='да'; ТД-ПМ по колонке D; пороги 44-ФЗ только из `@aemr/shared`;
  `classifySheet()` — единственный распознаватель листов; ноль тихих потерь данных.
- **Язык продукта**: ни один внутренний ключ (`UNMAPPED`, `uo`, `_org_itself`,
  `exec_count_pct`) в UI — только словарь (фаза 1). Закреплено тестом.
- **Один коммит = одна задача** с зелёным гейтом. Conventional commits.
- **Реестр интерактива** (спека §19.1): интерактивный элемент не появляется в коде, пока не
  внесён строкой в реестр (экран·hover·click·навигация·истоки·оценка).
