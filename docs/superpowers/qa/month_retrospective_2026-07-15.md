## §4. Спорные решения (приняты агентами без явного «да»)

1. **`isPBS=true` для аппарата ГРБС** (`shared/src/org-classify.ts:59`). Юридически орган
   власти = ПБС (ст.6 БК), но «аппаратом» признаётся и «Х»/пусто/«Администрирование» —
   эвристика на точных строках. Риск: мусорная строка колонки C тихо станет «Аппарат (ПБС)»
   и попадёт в канон «аппарат + сеть». Проверить: прогнать классификатор по всем 8 книгам,
   показать пользователю таблицу «строка C → класс» (org_canon это частично сделал — заморозить
   как fixture-тест).
2. **«Совместные закупки» → `isPBS=false`, тип joint_procurement** (`org-classify.ts:64`).
   Псевдо-организация — верно, но суммы совместных закупок при агрегации «по ПБС» выпадут из
   обеих корзин. Риск: недосчёт в разрезе «сеть». Проверить: сумма по joint_procurement
   строкам > 0? Если да — решить с пользователем, куда её класть (отдельная строка «Совместные»).
3. **severity-мэппинг канон-валидации источников** (`3800ac1`): какие расхождения листа —
   warning, какие error — выбирал агент (кроме `unclassified_sheet=warning`, который пользователь
   подтвердил через AskUserQuestion). Риск: заниженная severity прячет реальный дефект в общем
   списке. Проверить: таблица «правило → severity» на один экран пользователю.
4. **Публичный allow-list read-only деплоя ВКЛЮЧАЕТ не-GET** (`auth.ts:33-38`, коммит
   `2b4b88a`): `/api/refresh`, `sources/*/test|validate`, `validate-all`, `mapping/validate`
   доступны анониму. Мотив честный (кнопки просмотра должны работать), но `/api/refresh` — это
   полная перечитка всех книг из Google: анонимный цикл запросов = сжигание квоты Sheets API и
   нагрузка. Риск: тихий DoS демо и квоты сервис-аккаунта. Проверить/чинить: rate-limit на
   refresh или убрать из allow-list (кнопка пусть требует ключ).
5. **quarterExecution: факт засчитывается кварталу плана без сравнения дат**
   (`core/src/metrics/quarter-execution.ts:20-23`, `afbb771`). Комментарий заявляет
   «подтверждено пользователем» (Q1: УЭР 6/15=40% и т.д. из реального отчёта) — формула листа
   воспроизведена верно, НО дефект D8 из QA («исполнено В СРОК не существует, 244 просрочки
   соседствуют со 100%») этой метрикой не закрыт, а фаза 1.3 в мастер-плане обещала ровно
   «исполнение на дату среза». Риск: считать 1.3 закрытой — самообман. Проверить: спросить
   пользователя, нужна ли вторая метрика «в срок» отдельно.
6. **Serial-диапазон дат 40000..60000** (`shared/src/parse-sheet-date.ts:30`) — числа вне
   диапазона молча не считаются датами; выбор границ — агентский (2009..2064). Риск ничтожный
   сейчас, но `normalize.ts:82` до сих пор предупреждает только до 50000 — рассинхрон внутри
   одного класса, который сам свеп велел выровнять. Проверить: выровнять при закрытии семьи №1.
7. **attachUnifiedGrid: не-реестровый лист пропускается молча** (`c8cfb1e`,
   `snapshot.ts` — `findDept` + `continue`). Лучше кириллического мусор-ключа, но канон AGENTS.md
   «тихие провалы запрещены» требует сигнала, а не skip. Риск: новый лист в книге тихо не
   попадёт в сетку. Проверить: добавить counter/предупреждение в ingest-issues.
8. **МКОУ/МКДОУ → казённое (ПБС)** (`7f658b7`) — юридически обосновано ст.6 БК (казённые = ПБС),
   но правка «болевая» для отображения сети УО. Подтвердить у пользователя одним взглядом на
   новую разбивку.
9. **Render вместо запрошенного Vercel** (`f8c7233`, обоснование в DEPLOY-RENDER.md: нужен
   постоянный Node-процесс + SQLite, Vercel serverless не подходит). Решение технически
   правильное, но подмена платформы явно не подтверждалась. Риск: ожидания по цене/UX Render
   free-tier (засыпание инстанса). Проверить: сказать пользователю про cold-start free-плана.
10. **ШДЮ → «СВОД с месяцами»** как каноническое имя листа (`3800ac1`) + сохранение легаси
    `'ШДЮ'` только в кандидатах. Соответствует просьбе «шдю мы уже не используем», но
    переименование канона — операция с хвостами (доки/тесты/мэппинги). Проверить: греп «ШДЮ»
    по докам на стейл-упоминания.

**Счёт: 10 спорных решений;** приоритет подтверждения: №4 (безопасность/квоты) → №5
(семантика KPI) → №1/№2 (юр-канон) → остальные.
