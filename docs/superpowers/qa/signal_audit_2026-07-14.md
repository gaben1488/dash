## §3. Техзадачи агенту (корзины 1–2), по убыванию вопиющести

### 3.1. ❗ economyFlag не понимает канон AD «да/нет» → 77 ложных «Конфликт флага экономии»

**Файл:** `packages/core/src/pipeline/signals.ts`, строка ~343:
`const economyFlag = adText.includes('эконом');`

**Суть.** Канон столбца AD (см. правило `status_on_data_rows` в `packages/shared/src/rule-book`-слое:
expected «"да" или "нет"») — значения «да»/«нет». Подстроки «эконом» там не бывает →
`economyFlag` всегда false → случай (а) сигнала (AD=«экономия», факт ≥ план) мёртв,
а случай (б) («экономия >15%, флаг не определён») срабатывает и на строках, где флаг честно
проставлен: 53 срабатывания с AD=да, 24 с AD=нет (данные прогона 15.07).

**Что сделать.**
1. `economyFlag` = нормализованный AD равен «да» (учесть регистр/пробелы).
2. Ввести `economyFlagDetermined` = AD ∈ {«да», «нет»}; случай (б) срабатывает только
   при НЕопределённом флаге (пустой AD / Х / ·). AD=«нет» — это решение органа, не пробел.
3. Юнит-тесты: AD=да + экономия 30% → нет конфликта; AD=нет + экономия 30% → нет конфликта;
   AD=пусто + экономия 30% → конфликт; AD=да + факт ≥ план → конфликт (случай (а) оживает).
4. Проверить смежное: бейдж «Экономия» (`getSignalBadges`, `economyFlag && !economyConflict`)
   сейчас тоже никогда не показывается.

### 3.2. ❗ lowCompetition на 88% меряет артефакт заполнения, не конкуренцию

**Файл:** `packages/core/src/pipeline/signals.ts` (блок lowCompetition, ~строка 412).

УИО-квартиры, уже покрытые сигналом singleParticipant (дубль).

**Что сделать.**

2. Гасить при singleParticipant === true (дубль).
3. Останутся ~20 честных срабатываний с экономией 0–2% — оставить badge-only, как сейчас.

### 3.3. Словарь ЕП-кластеров слеп к местным формулировкам → ~70 ложных unmappedReasonEP

**Файл:** `packages/shared/src/dictionaries/ep-reason-clusters.ts`.

**Суть.** Частотка непокрытых значений M (полная — в `scripts/signal_audit_rows_2026-07-15.md`):

- «Распоряжение **Администрации ЕМР** КК от 03.09.2025 № 112 …» — regex EP_DECREE_112
  требует «распоряжени[ея]\s+а[ея]мр» (слитно «АЕМР») и не матчит «Администрации ЕМР» (≥3 строк, а
  в реальности больше: полная цитата уходит в UNMAPPED, когда нет «пп. N, п.1»);
- «данная процедура предполагает закупку разного назначения в малом объёме» (15),
  «закупка малого объема» (2) — нет кластера «малый объём» → п.4 ч.1 ст.93;
- «заключение контракта с издательством Просвещение» (11) — эксклюзивные права издателя
  (п.14 ч.1 ст.93), кластера нет;
- «обязанность заключать контракты с ФГКУ "ОВО ВНГ России…"» (7) — охрана Росгвардией,
  обязательная по закону;
- «единственный поставщик …» без слова «монополист»: тепловой энергии (2), электроэнергии,
  холодного водоснабжения, услуг местной связи (3), «оказания услуг» (7);
- «региональный оператор по обращению с ТКО» (2) — в signals.ts whitelist есть, в словаре нет;
- «на территории ЕМР только ССМП/ФБУЗ "Центр гигиены"/госэкспертизу проводит одно
  учреждение…» (4+4+6) — класс «единственный исполнитель на территории»;
- «закупка по предписанию УФСБ» (3), «закупка у Почты России» (2), «официальный дилер» (2).

**Что сделать.** Добавить/расширить кластеры (EP_DECREE_112 — альтернативный regex
«распоряжени[ея] администрации емр»; новые EP_SMALL_VOLUME, EP_SOLE_SUPPLIER_RESOURCE,
EP_PUBLISHER_EXCLUSIVE, EP_ROSGVARDIA, EP_SOLE_LOCAL_PROVIDER, EP_PRESCRIPTION), прогнать
`signal_audit.ts` повторно — целевой остаток UNMAPPED ≈ 170 (реальный мусор → §4/§5).

Пройди листы УО, УД, УИО. Отбери строки, где: Y > 0 (факт есть), AC > 0 (экономия есть),
AD пуст (нет ни «да», ни «нет»). Таких строк 93 (УО: 75, УД: 17, УИО: 1).
Для каждой строки читай комментарии (AF, при пустом — AE):
- комментарий содержит «экономией не является», «возвращена в бюджет», «вернули в резервный
  фонд», «ходатайство на снятие», «подлежит снятию» → поставить AD = «нет»;
- комментарий содержит «просим оставить … экономию», «экономия останется», «оставить на
  текущем мероприятии» → поставить AD = «да»;
- иначе — НЕ заполнять, внести строку в список «на решение УЭР» в итоговом отчёте.
Примеры для калибровки: УД стр.10 (AF «корректировка НМЦК, отображение экономии» — на
решение УЭР), УО стр.26 «Ремонт кровли» (AF «договор заключен», экономия 4 970,75 тыс —
на решение УЭР), УИО стр.11 (комментарий про подписание — на решение УЭР).
