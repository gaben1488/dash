# Попарные отношения сигналов: совпадения, включения, взаимоисключения

Источник — `docs/superpowers/audits/2026-08-21-signal-overlap/matrix.tsv`: одна строка файла = одна строка книги из боевой вселенной, колонка `signals` перечисляет сработавшие ключи. Ничего не досчитывалось и не оценивалось на глаз: все числа ниже — пересчёт множеств строк.

| параметр | значение |
|---|---:|
| строк во вселенной (все 8 книг ГРБС, СВОД исключён) | 8476 |
| строк хотя бы с одним сигналом | 3886 |
| ключей сигналов | 44 |
| пар сигналов | 946 |
| пар с непустым пересечением | 318 |

Сверка с `counts.tsv`: расхождений нет, все 44 ключей совпали по числу строк.

Обозначения: |A| — число строк, где сработал A; |A∩B| — общих строк; «доля A» = |A∩B| / |A|; Жаккар = |A∩B| / |A∪B|; «подъём» = наблюдённое пересечение, делённое на ожидаемое при независимости (|A|·|B| / 8476) — подъём 1 значит «совпадают случайно», 10 значит «в десять раз чаще случайного». Суммы — в тысячах рублей.

Сигналы разделены на **фон** — `signal:hasFact`, `signal:signed` и четыре `epgrade:*` (это состояние закупки и её классификация, они по построению висят на большинстве живых строк) — и **находки**, то есть собственно замечания. Включение находки в фон почти всегда структурно (нельзя иметь отклонение по факту без факта) и само по себе не повод сливать сигналы; интересны включения и совпадения находки в находку.
