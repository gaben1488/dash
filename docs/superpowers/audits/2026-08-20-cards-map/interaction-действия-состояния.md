продублировано стрелками; week-режим честно объявлен «не фильтром».

и не знает `page`. Пишется адрес через `history.replaceState` (`:242`), то
есть **кнопка «назад» браузера не отменяет ни фильтр, ни переход между
вкладками, а уводит с сайта целиком**.

## §4. Находки

### P0 — ломает смысл

**Н-P0-1. Пульт стирает уже прочитанные числа из-за одного неудачного
фонового обновления — и делает ровно противоположное тому, что обещает
собственный текст отказа.**
Адрес: `packages/web/src/pages/Dashboard.tsx:398` (`if (error) { return …аварийная карточка… }`)
против `packages/web/src/store.ts:926` и `:958`
(`error: 'Обновление не выполнено, на экране прежние числа. …'`).
Проверка `error` стоит раньше проверки `dashboardData`, поэтому любая
неудача автообновления (а оно идёт раз в 60 секунд, `Header.tsx:285`) убирает
с экрана весь Пульт и ставит «Пульт не удалось собрать». Числа при этом в
памяти есть. Соседняя вкладка делает правильно: `pages/Economy.tsx:297` —
`if (error && !dashboardData)`, а при наличии данных рисует полосу поверх
прежних чисел (`:384`).
Предложение: заменить условие на `error && !dashboardData`; при наличии
данных — полоса `role="status"` со словами «числа на экране прочитаны в
HH:MM, обновление не удалось» и кнопкой «Прочитать заново». Это же снимает
дубль: полоса отказа уже есть в шапке (`Header.tsx:703`).

**Н-P0-2. Пульт утверждает «Замечаний нет, состояние нормы», когда проверки
не прогонялись.**
Адрес: `packages/web/src/components/CriticalBannerV2.tsx:63-79`
(`if (criticalCount === 0 && warningCount === 0)` → зелёная плашка) при
источнике `hooks/useFilteredData.ts:91`
(`dashboardData?.snapshot?.issues ?? dashboardData?.recentIssues ?? []`).
Пустой список приходит и когда конвейер проверок не отработал, и когда
замечаний правда нет — плашка в обоих случаях зелёная. Это ровно тот случай,

## §5. Что в продукте уже сделано образцово (и что стоит тиражировать)

1. **Четыре рода пустоты на Мониторинге** (`pages/Monitoring.tsx:18-22, 248,
   260, 318, 441`) — эталон для всех остальных вкладок. Слова разные, действия
   разные, ни одна пустота не выдаёт себя за другую.
2. **Три ступени счёта в Реестре** (`pages/DataBrowser.tsx:1734, 1749` и
   подпись под таблицей) — «загружено N, показано M, скрыли такие-то фильтры»,
   с кнопкой снятия ровно того отбора, который срезал.
3. **Карточка строки** (`components/RowDetailCard.tsx:78-113`) — единственное
   в продукте окно с полной клавиатурной дисциплиной: Escape, ловушка Tab,
   возврат фокуса. Годится как образец для двух оставшихся окон.
4. **Клавиатура Реестра** (`pages/DataBrowser.tsx:812-874`) — стрелки, Home/End,
   Enter, «/», «?», Ctrl+C, и всё это названо в подписи под таблицей.
5. **Взвод перед необратимым** (`pages/Settings.tsx:1064-1088`) — готовый,
