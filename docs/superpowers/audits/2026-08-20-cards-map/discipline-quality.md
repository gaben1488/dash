# Карта вкладок «Дисциплина» и «Контроль» — до каждой цифры

Дата: 2026-08-20. Картограф: read-only проход по коду (страницы → компоненты → роуты → ядро).
Канон: docs/superpowers/audits/2026-08-14-interview-register.md (далее «п.N»).
Параллельно идёт волна правок (org-scope.ts, изоляция п.127, Dashboard) — места, где живая правка
может опередить карту, помечены «в движении».

Состав зоны:

- **Дисциплина** — `packages/web/src/pages/Discipline.tsx` + `components/discipline/*`,
  `components/timeline/UpcomingSection.tsx`, `components/workload/*`.
- **Контроль** — `packages/web/src/pages/Quality.tsx` (шесть вкладок):
  Сверка (`pages/Recon.tsx` + `components/recon/*`), Качество заполнения (`pages/Trust.tsx`),
  Замечания (`pages/Issues.tsx` + `components/quality/CommentAnnotationsSection.tsx` +
  `components/text-hygiene/*`), Оценка управлений (`components/scorecard/*`),
  Рекомендации (`pages/Recs.tsx`), Журнал (`pages/Journal.tsx`).

Итог по счёту: **36 карточек/секций**, из них **12 несоответствий канону** (7 из них — P0),
остальное — соответствия и слабости с конкретными идеями усиления.

## Часть III. Фильтры и сортировки зоны — сводно

**Ф-1. Что работает.** Глобальные оси: управления (OrgStrip/чипы) — применяются везде, кроме
Workload/RowEvents (Д-6) и NormalizationSection (II-E); год — Дисциплина (дела), Сверка
(годовые запросы); период/месяцы — честно ИГНОРИРУЮТСЯ с оговоркой на Дисциплине, Upcoming,
Workload, Оценке, Гигиене, Аннотациях (все п.58б-плашки на месте), применяются на Сверке
«По показателям» (fd.periodKey) и в Журнале (к дате события); поиск шапки — замечания/рекомендации
(fd), в журнал не лезет (сказано словами). Локальные: Замечания (поиск+серьёзность+статус),
Гигиена (книга+род), Журнал (поиск+тип), Сверка (4 вида).

**Ф-2. Комбинируемость** — хорошая внутри вкладок (чипы независимы, счётчики честно
пересчитываются после каждого слоя), но локальные фильтры разных вкладок не знают друг о друге:
из «Оценки» нельзя провалиться в «Замечания» уже отфильтрованным по управлению+механизму
(переходы навигации есть только у Trust).

**Ф-3. Сохранение состояния** — `qualityTab` в store (переживает навигацию), всё остальное —
локальный useState: вид Сверки, раскрытия, отборы Замечаний/Гигиены/Журнала теряются при
переключении вкладки (панель не активной вкладки размонтируется). P1: поднять хотя бы вид
Сверки и отбор Замечаний в store/URL — жалобы класса «внесла данные — из красного не ушла»
усугубляются потерей контекста.

**Ф-4. Изоляция п.127** — эталонно через `lib/selectors/dept-isolation.ts` (аннотации, гигиена,
оценка); нарушители: Workload/RowEvents (молча), NormalizationSection (молча), сервер журнала
(проверить правило районных событий).

**Ф-5. Режим подведов (org-scope, «в движении»)** — `lib/selectors/org-scope.ts` готов, образец —
Dashboard. В зоне НИ ОДНА секция его не использует. Естественные кандидаты: Гигиена текста
(колонка C — имя подведа уже в данных), Дисциплина (дела по подведам выбранного ГРБС), Сверка
«По подведомственным» (переход на UnitId).
