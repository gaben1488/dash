# Dash: проверенное основание для продолжения

Исследование возобновлено по новому запросу владельца 10.10.2026. Предыдущий макет не принят. Здесь сохранены разбор исходников, конкретный выбор для следующей версии и результаты проверок. Рабочее приложение не изменено, новый дизайн не выложен. Пульс исключён из переделки; его общая оболочка изучена.

**Начать с [консолидации](CONSOLIDATION.md):** русские схемы связей, выбранные решения, ограничения ядра и порядок внедрения. **[Разбор HTML](HTML-REVIEW.md)** объясняет каждый исходник и показывает оригинальные снимки. Это два рабочих документа для передачи Codex/Claude вместо ещё одного неподтверждённого макета.

## Что установлено

- Проверены 67 удалённых веток и полная доступная история Git. Найдены 12 текущих оригинальных HTML и один удалённый начальный прототип. Все 13 открыты; смысловые части и механизмы разобраны. Границы выборочной проверки состояний явно указаны в разборе.
- Планетарные семейства, автомобильные отделки, угол отбора и навигационный барабан действительно сохранены в репозитории. Оснований говорить, что Claude их не залил, нет.
- Предлагаемая основа: существующие барабаны года/недели, все 13 маршрутов, угол с раскрытием варианта Б, живая «Заря» внутри предметов, семейство «Космос» для следующего эскиза. Полные названия обеспечиваются компоновкой, а не сжатием и случайным переносом текста.
- Проверена связь ряда возможностей ядра с UI: аналитика массивов, оценка/контроль, история обновлений, отбор и архив уже частично реализованы. Старое общее утверждение «бэк умеет, фронт не показывает» недостаточно точно.
- **Ложный дубль составных номеров воспроизведён на текущем коде.** Для `173`, `173/1`, `173/2` правило `row_numbering` сообщает один повтор, а проверка `sequence-integrity` — ни одного. [Результат исполнения](evidence/numbering-reproduction.json). Это выявленный дефект, ещё не исправление.
- Формула и значение читаются, но полный договор о ячейке, примечаниях, обсуждениях и происхождении пока не закрыт. Поэтому архитектура данных и дизайн карточки должны дорабатываться совместно.

Три ранее подготовленных JSON проверок опубликованы с разрешения владельца: [замеры](../2026-10-10-dash-stop/signal-review/measurements.json), [результат](../2026-10-10-dash-stop/signal-review/result.json), [дополнение](../2026-10-10-dash-stop/signal-review/supplement.json). В тесте недельного контекста сначала срабатывают тайм-ауты, затем виден оставшийся контекст там, где ожидалось его отсутствие; влияние продолжающейся после тайм-аута работы — гипотеза для диагностики. Тайм-ауты и проверки не ослаблялись. [Короткий журнал](evidence/server-isolated-excerpt.txt).

Python и Docker локально повторно не запускались; их статус здесь основан на указанном CI. Проверка продукта на реальных данных и готовность целевого дизайна из зелёного CI не следуют.

## Следующая единица работы

Проверить и довести один путь: **сигнал → закупка → процедуры → источник и пояснения → действие → возврат**. Сначала устранить разную трактовку номера и определить недостающие контракты; затем собрать оболочку на существующем состоянии приложения. После этого графика и материал проверяются на реальных компонентах и распространяются на остальные разделы.

При продолжении сначала сравнить новые коммиты с указанной ревизией. Не перечитывать неизменные галереи, не устанавливать набор навыков ради самого набора, не повторять весь тестовый пакет без новой причины. Superpowers и Product Design/Impeccable применяются к постановке, первопричине, композиции и проверке результата. Новая БД не выбирается до проверки сохранения исходных данных без потерь.

Исторические документы в [архиве остановки](../2026-10-10-dash-stop/README.md) оставлены для передачи контекста. Их старые статусы «проверка заблокирована» и «история веток не исследована» заменены результатами этой страницы. Прежняя критика начального текущего года уточнена: база всех годов и начальный фильтр интерфейса — разные уровни.
