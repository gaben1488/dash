# Dash — единый макет, 10 октября 2026

Это одна версия для примерки: 12 разделов, без «Пульса». Она объединяет известные требования, исходные варианты Клода и результаты аудита. Перенос в действующий Dash не выполнялся. Рабочие книги не изменялись.

## Что предлагается принять

| Область         | Решение                                                                                      | Польза                                                                         |
| --------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Навигация       | Постоянное меню слева, короткие смысловые группы                                             | Все названия читаются; не нужно лечить нехватку места переносом и многоточиями |
| Верхняя линейка | Период → способы и бюджеты → управления и организации                                        | Всегда понятно, что сейчас показано                                            |
| Общий отбор     | Сохраняется между страницами; видны все отклонения от исходного состояния                    | Сравниваются одинаковые выборки                                                |
| Сброс           | Весь 2026 год, исходные разрезы; отмена 6 секунд                                             | Можно безопасно вернуться к общей картине                                      |
| Характер        | Чёрный графит, спокойные поверхности, кремовая типографика, «Заря» внутри активного элемента | Свет обозначает выбор, а не мешает чтению                                      |
| Цвет раздела    | Своя пара неба и горизонта, единые правила состояний                                         | Разделы узнаются, сохраняя общий характер                                      |
| Обновление      | Сначала «замечено», затем «проверено»; только по событию                                     | Пользователь видит состояние обработки                                         |
| Числа           | Открываемое основание; формула, полный результат и видимое значение отдельно                 | Значение можно объяснить и проверить                                           |
| Комментарии     | Примечание исходной ячейки отдельно от обсуждения с ответами и закрытием                     | Не теряются два разных вида пояснений                                          |
| Сигналы         | Ошибка данных, вопрос к связи, ошибка правила — разные основания                             | Совпавший номер не объявляется автоматически дублем закупки                    |
| Процедуры       | Одна строка на процедуру; связанные позиции внутри                                           | Доли и повторные ссылки не раздувают количество процедур                       |
| Узкий экран     | Меню раскрывается; вместо микроскопической линейки — выбор года и периода                    | Надписи и управление остаются читаемыми                                        |

Боковая навигация — предложение этого макета, а не ранее утверждённое пользователем решение. Ответ «переносить» из обрезанного вопроса Клода не считается одобрением многострочных вкладок.

## Границы достоверности

24 демонстрационных позиции, из них 22 за 2026 год и 2 за 2027. Часть ситуаций основана на аудите, но суммы и состав не являются текущей отчётностью. Прототип не подключён к Sheets, MongoDB, API или рабочим пользователям. Редактирование, ответы и рекомендации хранятся только до перезагрузки страницы. «Живой» коэффициент 9,8% — явно помеченная иллюстрация, не рассчитанный рабочий прогноз. Формула K4 — образец устройства карточки, не восстановленная формула каждого источника. Дата отчёта меняет подпись среза; исторические снимки в макете не реализованы. Пример выгрузки — HTML/CSV, не рабочий DOCX/XLSX.
