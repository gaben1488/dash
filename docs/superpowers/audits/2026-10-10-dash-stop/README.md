## Ошибка подхода и конкретные расхождения

Причина: построен самостоятельный образ приложения до составления проверяемой карты «требование → существующая функция → сохранение в макете». Проверка того, что демонстрационный интерфейс запускается, ошибочно подменила проверку полноты продукта. Качество нельзя оценивать только числом экранов, аккуратностью карточек и отсутствием ошибок в консоли.

| Область | Что установлено | Последствие для следующего исполнителя |
|---|---|---|
| Полнота источников | До макета визуально использована лишь часть коллекции; наличие файла в списке не означает его полного просмотра. В `main` присутствуют машинные отделки, планетарные семейства, варианты угла, барабаны | Не объяснять пропуски отсутствием файлов у Claude. Сверять конкретные версии и принятые решения |
| Навигация | Макет Codex заменил накопленную верхнюю навигацию боковой панелью; решение не подтверждено оценкой регрессий и выбором владельца | Не считать боковую панель принятым направлением. Изучить барабан навигации и полный набор маршрутов |
| Общая оболочка и «Пульс» | Исключённая страница содержит важные образцы общей оболочки, в том числе навигацию и стеклянные барабаны | Исключение содержания «Пульса» не исключает его как источника общих решений |
| Материал и цвет | Выставка содержит тематические семейства вкладок и машинные отделки. В своей версии Codex упростил их до привычных карточек и акцентов | Восстанавливать замысел по канону и источникам; выбор семейства остаётся за владельцем |
| Угол отбора | Есть три самостоятельных варианта; рекомендация автора варианта Б не равна принятию владельцем | Не канонизировать свой счётчик фильтров по умолчанию |
| Экономия | В `prototype/src/App.jsx` расчёт суммирует `plan - fact` по демонстрационному флагу. Корневой `AGENTS.md` требует сумму Z+AA+AB только при AD='да' | **Известная ошибка семантики прототипа. Его формулу нельзя переносить в рабочий код** |
| Периоды | Прототип сбрасывается к 2026 году и ограничивает годы списком 2025–2027. Канон задаёт базу всех лет; требуются многолетность и свободные даты | Макет не сохраняет всю модель периодов. Фильтры демонстрационных недель не доказаны на рабочих данных |
| Возможности сервера | Полной сверки серверных возможностей, API, текущих экранов и макета нет. В `packages/server/src/routes/analytics.ts` есть профили, соответствие, причины ЕП, антикоррупция, оценка, аномалии, прогноз, предметы, централизация, ссылки на ячейки | Наличие одноимённого экрана или карточки не подтверждает покрытие серверной функции |
| Данные и действия | 24 демонстрационные позиции; редактирование, ответы, рекомендации живут до перезагрузки; нет рабочих подключений, истории срезов и полного журнала решений | Считать показом отдельных взаимодействий. Не считать заменой рабочего реестра, источников и истории |
| Отчёты | Переключение трёх режимов демонстрируется, экспорт — пример HTML/CSV | Это не проверка трёх производственных Word-отчётов и их расчётов |
| Сигналы | Примеры сигналов в макете не равны рабочему реестру сигналов и его доказательствам | Не подменять результаты аудита демонстрационными карточками |
| Надписи вкладок | Проблема обрезки была сведена к переносу/компоновке без полной оценки навигационной модели, длины названий, иерархии и состояний | Решать как продуктовую задачу: узнаваемость, плотность, доступность и сохранение маршрутов |
| Принципы Apple | Проверяемого разбора официальных принципов и соответствия им нет; одного визуального стекла недостаточно | Не заявлять применение методологии Apple без конкретных критериев и проверки |
| Figma | Файл в Figma не создан; перенос в Figma не выполнен | Не выдавать HTML/React за готовый редактируемый дизайн в Figma |

Можно сохранить для обсуждения: единство выбранного контекста между страницами; показ источника числа; разделение примечания к ячейке и обсуждения с ответами/закрытием; различение вопроса к данным и доказанной ошибки. Это полезные гипотезы, а не одобрение всей визуальной концепции.

## Контекст для возможного возвращения

Начать с [мандата](../../specs/2026-08-22-mandate.md), [атласа продукта](../2026-08-20-cards-map/), [матрицы метрик](../2026-08-22-metrics-matrix.md), [определения готовности карточки](../../specs/2026-08-21-card-done-definition.md), требований владельца и [указателя исходных макетов](../../mockups/README.md). Отдельно восстановить статус каждого решения: принято владельцем / предложено / заменено / историческое.

Минимальная таблица перед новым макетом: «задача человека → требование → функция сервера → маршрут API → текущий экран → нужные состояния → вариант Claude → предложение → сохраняется/меняется/теряется → доказательство». Упомянутые владельцем `/grill-me` и собственное видение допустимы при новом запросе, после работы с уже имеющимися требованиями. Сейчас интервью и новый дизайн не запускаются.

Архитектурный выбор MongoDB/другого хранилища не принят. Сохранять отдельно введённое значение/формулу, рассчитанное и отображаемое значение, примечание к ячейке и обсуждения с ответами/закрытием; не считать номер строки устойчивой идентичностью закупки. Границы реально прочитанных листов и доступности комментариев — в сохранённом аудите, без новых заявлений о полноте.
