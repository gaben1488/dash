### Работа 2. Облик: шапка на месте, ширины из оригинала, форматы

Ширины колонок `A..P` взяты не с потолка, а из оригинала (`probe-origin-header.txt`):
59, 107, 390, 120, 106, 95, 118, 129, 102, 105, 112, 94, 93, 115, 320, 121 —

`Q` код 110, `R` способ 185, `S` исход 155, `T` состояние 140, `U` сверка 185.
На листе `25-26` те же ширины плюс `A` пометка 110, `K` победитель 320,
`U` судьба 120, `V` связанная 130, `W` скрыта 110. Было 100 пикселей у всех
23 колонок без разбора.

Закреплено: на восьми листах управлений две строки шапки и колонка номера,
на `25-26` — строка шапки и колонка пометки, на `Перечень ГРБС` — две строки,
на `_Правки` — одна. Шапка стала полужирной, с переносом и по центру, высота
строк 46 и 34 пикселя (было 21 — двухэтажный заголовок не помещался).

Форматы протянуты не по занятым строкам, а до тысячной, чтобы завтрашняя
запись попала в тот же вид: номер `0`, суммы `#,##0.00` (`D`, `I`, `J`,
`L`, `M`, `N`), даты `dd.mm.yyyy` по центру (`E`..`H`), текстовые колонки —
без переноса, по вертикали посередине.

**Исправлен обман шапки.** Подпись «Экономия, руб.» стояла в `L1`, то есть
ровно над колонкой «МБ», хотя относится к пятёрке `J..N` (ВСЕГО, проверка,
МБ, КБ, ФБ). Так в оригинале — проверено чтением, оригинал не тронут. В
книге 2.0 подпись перенесена в `J1` и склеена по `J1:N1`; заголовки пяти
новых колонок склеены по вертикали, как остальные.

**Отбора по шапке на листах управлений нет и не будет без решения владельца.**
Google отказывается ставить фильтр на диапазон со склеенными ячейками
(`You can't create a filter within a range containing merged cells`), а шапка
управлений двухэтажная и склеена по вертикали. Отбор поставлен там, где шапка
в одну строку: `25-26` (391 строка) и `_Правки` (573 записи). Разобрать
двухэтажную шапку управлений можно, но это меняет привычный вид — решение за
владельцем.

### Работа 3. Проверки ввода: подсказывают, но не запрещают

Все восемь проверок мягкие (`strict: false`). Жёсткие поставить нельзя:
в книге уже стоят 587 написаний заказчика вне перечня ГРБС и две даты
27.03.2024, которые исправлять запрещено, — строгая проверка не дала бы
сохранить то, что уже записано.

|---|---|---|
| Заказчик | `B3:B1000` / `B2:B1000` | список из `Перечень ГРБС!$D$3:$D$77` |
| Сумма НМЦК | `D` | только число, не меньше нуля |

Маска кода принимает и редкие законные формы: `ЭАС205/1-26` (номер лота) и

Границы дат выбраны так, чтобы книга ловила опечатки года (`0206`, `25026`)

### Работа 4. Подсветка находок: 97 правил вместо нуля

Словарь цвета в книге теперь двойной, и он назван вслух в легенде. Заливку
правок поставили один раз при сборке — она отвечает на вопрос «что здесь
трогали». Подсветка находок пересчитывается при каждой правке и ложится
поверх заливки — она отвечает на вопрос «что здесь не сходится сейчас».
Красок находок всего две плюс нейтральная, чтобы читатель не заучивал
палитру: песочно-красный `#F8D7DA` — величина не того рода, янтарный
`#FDECC8` — число не сходится, серый `#E8EAED` — данных нет либо ждёт
решения. Цвет текста задан явно (`#6E1B22`, `#6B4A00`, `#3C4043`), поэтому
подсветка читается и в светлой, и в тёмной теме Google.

Одиннадцать правил на каждом листе управления, девять на журнале `25-26` —
**97 правил**:

| Правило | Где | Условие |
|---|---|---|
| сумма записана текстом | `D`, `I`, `L:N` | заполнено, но не число |
| дата записана текстом | `E:H` | заполнено, но не число |
| дата вне 2024–2027 | `E:H` | число вне границ двух лет |
| код не по маске | `Q` / `P` | не подходит под семейства ЭА, ЭЗК, ЭЕП, ЭАС, ЭК |
| экономия не равна разности | `J` | `J ≠ D − I` при ненулевой цене |
| разбивка сошлась | `K` | «верно» — тёмно-зелёный бейдж отдела |
| разбивка не сошлась | `K` | «ошибка» — тёмно-красный бейдж отдела |
| разбивки нет | `K` | нейтральный серый |
| заказчик вне перечня | `U` / `T` | флаг ждёт решения владельца |

### Работа 4б. Два кода с номером лота дозаполнены

Проверка кодов вскрыла то, чего перепись не заметила: у двух строк колонка

правки в книге не осталось ни одной строки со способом «код не разобран» и
ни одного пустого кода.
