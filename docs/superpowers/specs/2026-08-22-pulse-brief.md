## §1. Верхняя линейка — семейство барабанов

> «ПОТОМУ ЧТО ТОГДА ЭТО БЫЛА ЧАСТЬ БАРАБАНА И БАРАБАН ОЧ КРУТО БЫЛ ПРОРАБОТАН.

### 1.1. Состав линейки

| слева направо | что это |
|---|---|
| Щит | полный, пять ролей, без сокращений |
| **Барабан навигации** | вкладки по три в ряд, разбиты на именованные группы |
| **Барабан периода** | годы, кварталы, месяцы — как есть в продукте |
| **Барабан недель** | как есть в продукте |
| **Барабан изменений** | новый: прокручивается на каждое изменение в книге; нажатие открывает журнал |

### 1.2. Барабан навигации — восстановление, а не изобретение

В истории репозитория кода `nd-drum` **нет**: коммит `a45af7a` принёс уже
надгробие «nd-drum removed — replaced by NavPills». Значит восстанавливается не
код, а физика — из живых барабанов `tg-drum` и `wr-drum`.

**Физика барабана, обязательная к переносу** (`index.css:1851` и `index.css:2240`):

- скругление 14 пикселей, отступ 4-5 по вертикали на 6-7 по горизонтали;
- стекло: `linear-gradient(180deg, rgba(255,255,255,0.09) 0%, rgba(255,255,255,0.03) 40%, rgba(255,255,255,0.01) 100%)`;
  тёмная пара — те же остановки со значениями 0.07 / 0.02 / 0.005;
- обводка `1px solid rgba(255,255,255,0.10)`, в темноте `rgba(255,255,255,0.08)`;
- размытие подложки `blur(16px) saturate(160%)` с приставкой для веб-набора;
- тени слоями: две внутренние (свет сверху `inset 0 1px 0 rgba(255,255,255,0.14)`,
  тень снизу `inset 0 -1px 0 rgba(0,0,0,0.08)`), три внешние на подъём
  (`0 2px 4px`, `0 4px 12px`, `0 8px 24px` чёрного с прозрачностью 0.06/0.08/0.05)
  и две латунные `0 0 16px rgba(191,161,97,0.05)` и `0 0 32px rgba(191,161,97,0.02)`
  как окружающее свечение;
- наведение: `transform: scale(1.01)` за 180 мс по кривой
  `cubic-bezier(0.23, 1, 0.32, 1)`, обводка светлеет до `rgba(255,255,255,0.14)`;
- крайние строки тусклее и мельче центральной — барабан, а не список;
- состояние «частично» имеет собственную краску (как `tg-year-partial`);
- колесо мыши листает; есть клавиатурный дубль.

### 1.3. Барабан изменений

Правая часть линейки. Ведёт себя как барабан, а не как лента:

- каждая новая правка в книге **прокручивает барабан на одну строку**;
- в центральной строке — последнее изменение, крайние тусклее и мельче;
- строка короткая: время, книга, что стало. Набор моноширинный;
- нажатие раскрывает журнал; в журнале матрёшка «когда обновилось → какие
  изменения в какое время»;
- три состояния: тишина, поток, потеря связи.

### 1.4. Корзины внутрь Реестра

Формулировка из макета облика: вкладки-корзины (мелкие разделы) не занимают
место в линейке, а живут внутри Реестра. Это освобождает линейку под барабаны.

## §3. Требования «везде» (проверяются на каждой карточке)

| Требование | Что значит на карточке |
|---|---|
| **ФБ / КБ / МБ** | у любой денежной величины есть разбивка по трём бюджетам |
| **ЕП / ЭА** | у любой величины есть разрез по способу закупки |
| **ТД / ПМ** | разрез «текущая деятельность» против «программное мероприятие» |
| **Режим ГРБС / режим организаций** | УО укрупнённо — или УО как организация плюс её подведы |
| **БЗ** | карточка знания у каждого числа: механизм, пороги, правовое основание, куда ведёт |
| **Провенанс** | откуда число: книга, лист, графа, момент чтения, формула |
| **Контекст** | к чему число относится: перимет, доля от целого, сравнение |
| **8 % ↔ живой процент** | переключатель ставки, работающий как режим на всём экране |
| **Любое сочетание кнопок** | ни одна комбинация отборов не даёт пустоты без объяснения |
| **Любая навигация** | после провала и возврата отбор сохраняется, адрес возврата известен |

## §6. Облик

- **Палитра расширяется при разделении ролей.** Голубой заменить более интересным
  и красивым родственником — владелец просил найти аналог, а не оставить как есть.
- **Хром сменить.** Шоколадно-коричневый и болотный владелец забраковал прямо
  («я уже ругался на тебя по этому цвету»).
- **Оранжевый не нужен вовсе** — кнопки «Оттиска» нравятся, оранжевый нет.
  Повторено дважды, значит не обсуждается.
- **Тёплое само по себе не запрещено.** Уточнение владельца 22.08: «запрет на
  тёплое был не совсем корректен — я запрещал какашечный коричневый хром (хотя
  с учётом что он был бы в светлой теме то наверное ок)». Значит запрещён
  коричневый хром, а тёплые подложки в светлой теме допустимы.
- **Ритм сетки.** Приговор «раскидал рандомно виджеты» лечится единой сеткой:
  фиксированный шаг колонок, три допустимых размера карточки, выравнивание
  верхних краёв в ряду, никаких одиночных полукарточек в конце ряда.
