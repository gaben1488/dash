# Справочник причин отклонения сроков: что пишут исполнители и что это значит

Разведка 04.08.2026 по восьми книгам ГРБС (выгрузка 26.06.2026), колонка U
«Причина отклонения». **494 строки, 239 разных формулировок** — то есть почти
на каждые две строки своя редакция текста. Ниже — что за этим стоит на самом
деле, сгруппированное по смыслу, с числами и с тем, кто может это устранить.

Реализация: `packages/shared/src/dictionaries/deviation-reason-clusters.ts`
(16 кластеров, распознаёт 76 % строк). Оригинальный текст исполнителя не
теряется — продукт показывает и его, и нормализованную причину.

## §2. Что из этого следует для продукта

**Треть всех отклонений — деньги, а не закупки.** 165 строк «нет
финансирования» плюс 22 «кассовый план» — это 38 % объяснений, и все они
адресованы не ГРБС, а бюджетному процессу. Показывать их вперемешку с
«поставщик задержал подписание» — значит прятать системную проблему за
частными случаями. Отсюда поле `owner` в словаре: продукт может сказать
«из 494 отклонений 187 не в компетенции управления».

**77 строк — не отклонения вовсе, а правки таблицы.** Плюс 11 «Исполнен»,
5 «Перенос без причины», 5 «новая позиция» — почти сотня строк, где колонка
заполнена не по назначению. Это метрика качества ведения листа, и её нужно
показывать отдельно, иначе она искажает статистику срывов.

**Формулировка «этапность муниципальных программ»**, о которой вы
спрашивали, в текущей выгрузке **не встречается**: в 239 формулировках слово
«этап» есть один раз, и то про пробу песка в карьере. Про программы пишут
иначе — «требуется внесение изменений в кассовый план и в программу в части
финансирования». Если формулировка появится в новых неделях, словарь
дополнится: место для кластера «изменение муниципальной программы»
подготовлено.

## §3. Как этим пользоваться дальше

1. **Свести к вводу из списка.** Шестнадцать кластеров покрывают 76 % строк.
   Если исполнитель будет выбирать причину из выпадающего списка, а свободный
   текст оставлять уточнением, статистика станет считаемой без словаря.
2. **Разделить ответственность.** Причины с `owner: 'финансовый орган'` —
   это повестка для УФБП, а не для ГРБС; с `owner: 'поставщик'` — повод
   для претензионной работы.
3. **Отделить «мнимые» отклонения** (`DEV_DATA_ENTRY_ERROR`, `DEV_DONE`,
   `DEV_NEW_ROW`, `DEV_RESCHEDULED`) от настоящих: иначе доля срывов в
   отчёте завышена почти на сотню строк.
