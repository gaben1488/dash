# Переход на Tailwind четвёртой ветки — карточка волны и план

> Заполнено по харнессу работы (docs/superpowers/specs/2026-08-18-work-harness.md).
> Решение владельца 18.08.2026: «порядок устраивает, ставь миграцию следующей волной».

## Карточка волны

**Источник обязанности.** Решение владельца 18.08 после разбора плюсов и минусов.
Побочный повод: несовместимость библиотеки слияния классов (её третья ветка
собрана под четвёртую ветку Tailwind) — сегодня закреплена вторая ветка, после
перехода возвращается третья.

**Задача одной фразой.** Перевести веб-часть на четвёртую ветку Tailwind без
изменения внешнего вида и поведения продукта.

**Читатель.** Пользователи продукта — они не должны заметить ничего, кроме
скорости. Разработчик — получает единый дом темы и быструю пересборку.

**Не делаем.** Не меняем оформление, не вводим новые компоненты, не трогаем
логику. Любое «заодно улучшил» — вне этой волны.

**Готовое.** Официальный переходник Tailwind выполняет механическую часть
(переименования, конфигурация, подключаемый модуль). Ручная часть — то, чего
переходник не умеет: наши переопределения палитр, классы, собираемые в
переменных и условиях, плагин анимаций.

**Данные.** Замер по нашему коду сделан:

| Класс третьей ветки | Становится | Вхождений |
|---|---|---|
| `shadow-sm` | `shadow-xs` | 75 |
| голый `rounded` | `rounded-sm` | 123 |
| `rounded-sm` | `rounded-xs` | 8 |
| `outline-none` | `outline-hidden` | 45 |
| `flex-shrink` | `shrink` | 52 |
| `blur-sm` | `blur-xs` | 8 |
| голый `ring` | `ring-3` | 4 |
| `ring-offset-*` | проверка вручную | 11 |

Итого 326 замен. Конфигурация: 121 строка настроек → директива темы в стилевом
файле. Особое место: в настройках переопределены стандартные палитры (синяя,
небесная, индиговая отрисовываются кремовыми) — это сотни мест в коде, и в
четвёртой ветке переопределение делается переменными темы.

**Приёмка.**
1. Проверка типов и тесты всех пакетов зелёные (веб сейчас: 117 файлов, 1161 тест).
2. Сборка проходит, размер стилей не вырос более чем на десятую часть.
3. Библиотека слияния классов возвращена на третью ветку, страж
   `tailwind-merge-compat.test.ts` зелёный.
4. Визуальная сверка по чек-листу приёмки внешнего вида (32 пункта
   документа дизайн-системы) на каждой вкладке **в обеих темах**.
5. Отдельно проверяются: тени, скругления, кольца фокуса, обводка — то, что
   меняет вид при переименовании.
6. Кремовые палитры на месте: ни одного синего элемента хрома.

**Швы.** Волна не трогает данные и расчёты; шов один — общий вид продукта
остаётся прежним.

**Зоны файлов.** `packages/web/**` целиком (стили, настройки, компоненты,
страницы), `packages/web/package.json`, `postcss.config.js`,
`tailwind.config.ts` (удаляется). Не трогаются: `packages/{core,server,shared}/**`.
**Волна запускается только когда веб-зона свободна** — параллельные волны,
правящие компоненты, обязаны завершиться.

**Риски и откат.**

| Риск | Мера |
|---|---|
| Старые браузеры на рабочих местах (нужны Safari 16.4, Chrome 111, Firefox 128) | Проверить версии у исполнителей ДО выката; при находке старых — отложить |
| Переопределение палитр сломается — половина интерфейса станет синей | Отдельный шаг с проверкой на каждой вкладке; тест на классы хрома |
| Плагин анимаций несовместим | Проверить первым делом; при несовместимости — заменить или перенести анимации в стили |
| Классы, собираемые в переменных, переходник не найдёт | Ручной обход по списку мест сборки классов |
| Тонкие тени и кольца изменят вид | Сверка по чек-листу, скриншоты до и после |
| Наборы готовых компонентов собраны под третью ветку | Проверить каждый подключённый набор |
| Что-то поехало и не заметили | Ветка + откат одним переключением; выкат только после визуальной сверки |

## Порядок работ

1. **Проверка окружения.** Браузеры на рабочих местах (ответ владельца), плагин
   анимаций, подключённые наборы компонентов.
2. **Ветка.** Отдельная ветка, чтобы откат был одним движением.
3. **Переходник.** Официальный инструмент обновления; разбор его отчёта.
4. **Конфигурация.** Перенос темы в стилевой файл: кремовая шкала, цвета
   бюджетов, шрифты, переопределения палитр — в переменные темы.
5. **Ручные замены.** 326 классов + места, где классы собираются в переменных.
6. **Библиотека слияния классов** возвращается на третью ветку.
7. **Гейт.** Типы, тесты, сборка, размер стилей.
8. **Визуальная сверка.** Каждая вкладка, обе темы, узкий экран, состояния
   загрузки и пустоты; скриншоты до и после.
9. **Показ владельцу** до выката.
10. **Выкат** и наблюдение.

## Что требуется от владельца

- Версии браузеров на рабочих местах исполнителей (ключевое условие).
- Приёмка внешнего вида после сверки, до выката на прод.
