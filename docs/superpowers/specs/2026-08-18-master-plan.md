## 1. Последовательность волн

**Волна I (сегодня): баги + хвосты.**
Фикс `planYearMissing` → N-канон + сигнал «сломана формула производной»
(O/P от N, R/S от Q) с адресом ячейки; провенанс номеров строк пульта
(диагноз: источник данных); периметр управления в разрезе AD Контроля;
скан изменённого свода ТД-ПМ + корректировка программы; гейт умершей
волны tabs-100 → коммит → деплой. История строки «Русь» по журналу.

**Волна II: сигналы 2.0 + Мониторинг.**
Гигиена текста (опечатки по словарям, двойные пробелы, невидимые символы,
регистр) — карточками диагноста «как исправить», без упрёка; сигнал
нумерации A (пропуски/дубли); сигнал «экономия по ЕП» (п.98м — разбить
factExceedsPlan/deviation по способу); наполнение вкладки Мониторинг по
спеке; связка ЭА-кодов книга↔мониторинг.

**Волна III: ЕП-аналитика + живой коэффициент (проект).**
Справочник обоснованности ЕП (категории босса: монополист, КП в адрес УЭР,
наименьшая цена + пункты ст.93 из справочника legal-basis-93); разметка
корпуса; экраны «доля необоснованного ЕП» + динамика по неделе/месяцу/
кварталу (из срезов + журнала); документ-проект «живой коэффициент
экономии»: методика (скользящее среднее % снижения по завершённым торгам
мониторинга), сравнение с 8%, план замены формул в листах и модулях —
НА УТВЕРЖДЕНИЕ владельцу до правки таблиц.

**Волна IV: Реестр-эталон + консолидация.**
Спека эталона (таблица Google-уровня + карточная мобильная, одна модель,
слои: сигналы/ошибки/рекомендации/стадии); переезд страниц-списков в слои;
одно место сигналов (п.88).

**Волна V: Закупки 2.0.**
Спека новых таблиц: разбивка НМЦК (план-мин/план-макс), справочники
(предметы, организации, причины), колонка ИКЗ (в.64), модель экономии
«свободный остаток + торги = общая» (п.98н), возврат экономии
(перераспределение, в.68-72), защита данных/группы. После утверждения —
билд: сервисный аккаунт создаёт книги с дампом наших данных и целостными
формулами, папка «Закупки 2.0» на Drive владельца, права редактора.
Приёмка: property-тесты формул на дампе, сверка итогов со старыми листами.

**Волна VI: выгрузки + справочник предметов.**
Экспорт-комплекты по референсу (xlsx листов ГРБС с подсветками сигналов,
PDF свода, docx-отчёт уже есть); справочник предметов закупок:
кластеризация корпуса → предложение групп → разметка владельцем кликом
(как виды yearlong, п.83).
