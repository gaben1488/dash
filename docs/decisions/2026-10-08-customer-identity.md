# Устойчивые идентификаторы справочника

Решение: отдельный технический UUID в S («ID учреждения») справочника заказчиков. UUID сохраняется с записью при переименовании и перестановке; адрес ячейки остаётся только адресом доказательства. Группы совместных заказчиков получают такой же технический ID, без выдуманного ИНН. Пустой, неверный или повторный UUID диагностируется; по нему нельзя объединять записи. Новые записи получают ID при обновлении справочника. Существующие ID не перезаписываются. Никакие диапазоны не защищаются.

Сопоставление существующих написаний по алиасам сохраняется. Добавление ID не подтверждает юридические реквизиты и не разрешает спорные совпадения.
