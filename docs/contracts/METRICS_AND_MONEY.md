# Контракт арифметики, денежных смыслов и статусов метрик

**Статус:** proposed distillation. Законодательные пороги и современные денежные данные требуют проверки на дате применения, старые тестовые числа не являются текущими.

## Сначала предметное определение, затем цифра

Каждая метрика имеет: `metric_id`, человеческое название, математическое выражение, исходные колонки/сущности, числитель, знаменатель, единицы, режим времени, все оси фильтра, null-policy, asOf, источник расчёта, legality/normative category, тест и ссылку на строки.

- `amount_deviation = fact_total − plan_total`. Минус — недоосвоение/недовыполнение по направлению источника; нельзя инвертировать знак для «позитивной» визуализации.
- Legacy key `savings_pct` на официальном листе соответствует **потрачено, % = факт/план**. Не изображать это как экономию.
- Подтверждённая экономия по master-строке допускается при корректной фактической дате Q и отметке `AD="да"`, тогда сумма `Z+AA+AB`. Не допускается формула `план−факт` без отдельного предметного названия. AC — производный контроль суммы, AD — явный гейт.
- Бюджетный план H:J, НМЦК, контрактная цена, снижение цены победителя, учтённая УФБП экономия и перераспределённые лимиты — **разные денежные сущности**. Нельзя смешивать их в одном числителе.
- Классификатор способа закупки — единый `classifyMethodGroup` из `@aemr/shared` / принятого shared-layer; неизвестное непустое значение = `UNKNOWN`, а не автоматически КП. Классификация «ТД-ПМ» основывается на D (программе) и F (виде деятельности), не только на буквенной подписи.
- Пороги 44-ФЗ, если применяются, берутся из проверенного общего набора `LAW_44FZ_THRESHOLDS` с версией и единицами. Оценочный риск не называй юридическим нарушением.

## Денежная атрибуция мониторинга

Основная процедура, переоформленные попытки и доли участников — разные сущности. Количество считается по действующей основной процедуре без дублей попыток. Деньги участников отражают **только подтверждённо введённые доли**, остаток хранится у основной процедуры. Инвариант: сумма распределённых долей и остатка равна исходной сумме; необоснованные связи не получают денег. Не изменять мастер факт из-за цены торгов.

## Период, выборка, пустота

- Выбранный год/квартал/способ/бюджет/ГРБС/подведомственная организация — реальные оси только там, где источник поддерживает соответствующий отбор. Неприменимость озвучивай, не имитируй применение.
- `null`, настоящая 0, unread source, `#REF!`, skipped row, future period, `not applicable`, нет сравнительного среза — отдельные состояния. Недоступную половину сравнения никогда не считать нулём.
- Единый общий абсолютный план по всем годам отличается от плана выбранного года; нельзя суммировать многолетние срезы, пока политика строк без P не определена.
- Официальный СВОД и расчёт могут отвечать на разные вопросы. При несовпадающем периметре маркируй `NOT_COMPARABLE`, а не ложное расхождение.
- Сигнал содержит природу, severity, доказательство, действие и источник; разные карточки с одним механизмом объединяются, но не стирают разные предметные состояния.

## Проверки до релиза

- Fixture из `docs/METRICS_CONTRACT.md:L88-L119`: три строки — план 1700, факт 1150, отклонение −550, учтённая экономия 35 (в этой иллюстрации). Тестовое число не переносить в производство.
- Страж `AD="нет"` или `Q` нет: исключить экономию без изменения других показателей.
- Проекция двух бюджетных доль: контроль суммы до копейки и правильного ГРБС.
- `N` корректна при утрате формульных O/P: это диагностика формулы, не «нет финансирования».
- Симметричный фильтр: видимые строки = сумма карточки по тем же scope и моменту чтения.
