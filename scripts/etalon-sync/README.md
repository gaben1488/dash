# etalon-sync — перенос эталонных настроек книг ГРБС

Инструмент переноса «золотого набора» (УФ-правила, защиты, проверка данных,
форматы, справочник подведов) на книги управлений. Источник канона — книга УО
плюс контрольные роли старого 47-набора (решение владельца 29.08.2026).

## Железный порядок (мандат владельца)

1. `node scripts/etalon-sync/plan.cjs --book <ключ>` — строит ПЛАН от свежего
   дампа: файл с полным диффом «было → станет» в
   `E:/aemr-dumps/etalon-sync/plans/`. В книгу не пишет НИЧЕГО.
2. Владелец читает превью и даёт однозначное «да» (можно «да, кроме пункта N»).
3. `apply` (появится после первого утверждённого плана) исполняет строго
   утверждённый план: перед записью снимает снапшот затрагиваемых сущностей
   (файл отката), сверяет, что книга не изменилась с момента плана, после
   записи делает контрольный дамп и сверку «план ↔ факт».
4. Без утверждённого плана запись запрещена. Каждая волна — отдельный план.

## Решения владельца (29.08.2026)

- Р1: канон УФ — «золотой набор»: полный контроль (все роли старого 47-набора
  + диалект УО), синтаксис оптимальный (REGEXREPLACE-контроль формул, ROUND
  в контроле сумм против копеечных ложных срабатываний, открытые диапазоны
  4:низ, якорь $A4).
- Р2: проверка данных по модели УО со справочником: правка справочника в
  «_Настройки» (колонки H/I/J) сразу отражается в выпадающих списках листа.
- Р3: способ закупки — строго «ЕП»/«ЭА» («ЭА и аналоги» уходит).
- Р4: списки редакторов защит — люди не меняются (объединение текущих списков
  книги), пока владелец не продиктует иное.
- Р5: служебную запись aemr-sheets-bot добавить в редакторы защит УО — да.
- Р6: тёмные подведы переводятся на канон УО; на листах подведов статические
  заливки убираются полностью; на основных листах убирается только белая
  статика (#FFFFFF и theme:BACKGROUND), цветные заливки остаются.

## Файлы

- `canon.cjs` — золотой набор: правила УФ, целевые защиты, проверка данных,
  форматные политики. Единственный дом канона.
- `plan.cjs` — генератор превью-плана по книге (read-only).
- `lib.cjs` — общее: авторизация, адресация, цвета.

Кодировки: вывод — UTF-8 файлы; консоль — только ASCII.

## Чипы выпадающих списков (важно)

Стиль отображения выпадающего списка («чип» против «стрелки») в Sheets API v4
НЕ существует (DataValidationRule: condition/inputMessage/strict/showCustomUi —
и всё). Любая программная перезапись правила валидации сбрасывает чип-вид на
стрелку. Поэтому:
- чипы включаются только руками: выделить колонку → Данные → Проверка данных →
  правило → параметры отображения → «Чип» (один раз на колонку);
- ПОВТОРНО ПРОГОНЯТЬ validation-фазу (applyMain) или v7-strictCDE можно только
  при изменении канона валидации — иначе собьются чипы, выставленные владельцем.
  Волны v8 (УФ) и final-verify валидацию не трогают.
