# AEMR — вход для Claude

Общие инструкции находятся в [AGENTS.md](AGENTS.md): порядок чтения,
разрешение противоречий, предметные инварианты, работа с веткой и проверки.
Этот файл не задаёт второй процесс или собственный реестр готовности.
Карта документов — [README](README.md#documentation-map), задача и текущая
граница доказательства — [PLAN](docs/PLAN.md#current-execution).
При возобновлении не переносить старые статусы PR/worker в новый ответ.

## Работа с репозиторием

- Использовать команды `package.json` через закреплённый `corepack pnpm`.
  Матрица проверок по типу изменения — AGENTS, эксплуатация — RUNBOOK.
- Не коммитить секреты, service-account JSON, SQLite/WAL, исходные отчёты,
  локальную память, временные артефакты и `*.tsbuildinfo`.
  Сохраняется разрешённое владельцем 29.07.2026 исключение: обезличенные
  `packages/core/src/report/__fixtures__/week-*.json` для регресса против
  ручного отчёта. Это не разрешение публиковать другие первичные материалы.
- Документировать исполненный путь отдельно от целевого. Команда, маршрут,
  роль доступа или схема не считаются реализованными по одному дизайн-документу.
- При изменении безопасности/проверочных команд согласовать SECURITY/REVIEW;
  текущую реализацию доступа проверять по middleware и Caddy, не по старому
  совету положить production-ключ в localStorage.

## UI: обязательные источники

До работы с экраном прочитать PRODUCT, DESIGN и полный
[DoD карточки](docs/superpowers/specs/2026-08-21-card-done-definition.md).
Сохранить рабочую геометрию, сценарии, выгрузки, фильтры, историю, черновики,
подведов, происхождение чисел и различие Google-обсуждения/решения Dash.
При изменении UI обновить затронутую карту в существующем
[атласе](docs/superpowers/audits/2026-08-20-cards-map/сводная-карта.md),
не объявляя весь августовский атлас перепроверенным.

Для оболочки/дизайн-системы учитывать
[отказ от макета #70](https://github.com/gaben1488/dash/blob/f338af5a827841dd2eecf5086bbf7f257c222d8b/docs/superpowers/audits/2026-10-10-dash-stop/README.md)
и [postmortem #83/#88](docs/superpowers/audits/2026-10-10-design-library-postmortem.md).
Тестовая демонстрация использует один согласованный набор данных; действительные
токены проверяются во всех состояниях и Portal, фрагмент кода — компиляцией.
Исправленный исторический finding не открывается вновь без воспроизведения.
Макет/зелёный CI не являются визуальным одобрением или production acceptance.
